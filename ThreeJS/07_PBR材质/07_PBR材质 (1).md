# 07 PBR 材质

> 复习方式：每节先看「一句话结论」，能回忆起来就跳过；想不起来再看代码和「坑」。

## 1. PBR 是什么，用哪个材质

**一句话结论**：PBR（Physically Based Rendering，基于物理的渲染）按照真实世界的光学规律来计算材质外观。Three.js 里对应两个材质：`MeshStandardMaterial`（标准）和 `MeshPhysicalMaterial`（物理，是标准材质的扩展版）。

```text
MeshStandardMaterial      金属度、粗糙度、环境贴图……
        ↓ 继承
MeshPhysicalMaterial      上面全部 + 清漆层、透光（玻璃）……
```

| 材质 | 什么时候用 |
|---|---|
| `MeshLambertMaterial` | 只要有明暗、不要求质感（第 6 章用过） |
| `MeshStandardMaterial` | 大多数需要真实质感的场景，GLTF 模型的默认材质 |
| `MeshPhysicalMaterial` | 车漆、玻璃这类标准材质做不出来的效果；计算量更大 |

---

## 2. 金属度 metalness 与粗糙度 roughness

**一句话结论**：PBR 最核心的两个参数。`metalness` 决定**像不像金属**，`roughness` 决定**表面光不光滑**，取值都是 0~1。

```js
loader.load('./metal/金属.glb', gltf => {
  gltf.scene.traverse(child => {
    if (child.isMesh) {
      child.material = new THREE.MeshStandardMaterial({
        metalness: 1,    // 完全金属
        roughness: 0.5,  // 半粗糙：反射是模糊的
      })
    }
  })
  model.add(gltf.scene)
})
```

| 参数 | 0 | 1 | 中间值 |
|---|---|---|---|
| `metalness` | 非金属（石头、木头、塑料） | 金属 | 生锈、氧化的金属 |
| `roughness` | 镜面，反射清晰 | 完全粗糙，没有清晰反射 | 磨砂金属、哑光塑料 |

**默认值**：`MeshStandardMaterial` 的 `metalness` 默认是 **0**，`roughness` 默认是 **1**（非金属、完全粗糙）。

**坑**
- `metalness: 1` 的模型**只靠反射环境来显示外观**。只加了灯光、没有环境贴图时，金属看起来会发黑、发暗。这是第 3 节环境贴图存在的意义。

## 3. 环境贴图 envMap

**一句话结论**：用 6 张图拼成一个包住场景的立方体（CubeTexture），赋给材质的 `envMap`，模型表面就能反射出这个环境。

### 加载立方体纹理

```js
const textureCube = new THREE.CubeTextureLoader()
  .setPath('./环境贴图0/')   // 先设置公共路径
  .load([
    'px.jpg', 'nx.jpg',     // +X  -X
    'py.jpg', 'ny.jpg',     // +Y  -Y
    'pz.jpg', 'nz.jpg',     // +Z  -Z
  ])
```

- `CubeTexture` 是立方体纹理，父类是第 6 章用过的 `Texture`。
- 6 张图的**顺序是固定的**：px、nx、py、ny、pz、nz，即先正后负，按 X→Y→Z 排列。

### 应用到材质

```js
child.material = new THREE.MeshStandardMaterial({
  metalness: 1,
  roughness: 0.5,
})
child.material.envMap = textureCube       // 反射这个环境
child.material.envMapIntensity = 1        // 环境贴图的影响强度
```

### envMapIntensity

它是一个**倍数**，用来放大或减弱环境贴图对模型的影响：

| 值 | 效果 |
|---|---|
| `0` | 环境贴图不起作用 |
| `1` | 默认强度 |
| `> 1` | 比环境本身更亮（第 6 节车漆用的是 2.5） |

**反射清晰还是模糊**取决于 `roughness`，**反射多少**主要取决于 `metalness`。`envMapIntensity` 只是在这个基础上整体调亮或调暗。

**坑**
- 6 张图顺序搞错，反射出来的环境会错乱（比如天空出现在侧面）。
- 只设置了 `envMap` 却看不到反射：检查 `metalness` 是不是 0、`roughness` 是不是 1。非金属又完全粗糙的表面，几乎看不出镜面反射。

## 4. envMap 和 map 的区别

**一句话结论**：`map` 是**贴在**表面上的图，`envMap` 是表面**反射出来**的景象。

| | `material.map` 颜色贴图 | `material.envMap` 环境贴图 |
|---|---|---|
| 作用 | 定义表面本身的颜色、图案 | 模拟对周围环境的反射 |
| 依赖 UV 坐标 | 是 | 否 |
| 换个角度看 | 图案固定在表面上不动 | 反射内容随视角变化（像照镜子） |
| 纹理类型 | `Texture`（一张图） | `CubeTexture`（6 张图） |

所以看到"环境贴图没有像贴纸一样贴在模型上，而是随相机移动而变化"，这是正确的效果。

## 5. 环境贴图也是光源（IBL）

**一句话结论**：环境贴图不仅提供反射，还能**照亮模型**。即使场景里一盏灯都没有，用了 envMap 的 PBR 模型也能看得见。这叫 **IBL（Image-Based Lighting，基于图像的照明）**。

可以把环境贴图想象成包住整个场景的一个**会发光的天球**，上面每个像素都在发光：

| 计算的部分 | 作用 |
|---|---|
| 镜面反射（Specular） | 映出环境的影像，就是第 3 节看到的反射 |
| 漫反射（Diffuse） | 环境中的亮部（天空、窗户）照亮模型，暗部贡献的光少 |

### 给 GLTF 模型直接加环境贴图

GLTF 的默认材质本来就是 `MeshStandardMaterial`（第 6 章），不用替换材质，直接加 envMap 即可：

```js
loader.load('./工厂/工厂.gltf', gltf => {
  gltf.scene.traverse(child => {
    if (child.isMesh) {
      child.material.envMap = textureCube
      child.material.envMapIntensity = 1
    }
  })
  model.add(gltf.scene)
})
```

实验：把 `main.js` 里的灯光注释掉，模型依然可见，光照全部来自环境贴图。

### 环境贴图的色彩空间（接第 6 章）

环境贴图的 6 张 jpg 是照片类的颜色图，应该和第 6 章的颜色贴图一样，声明为 sRGB：

```js
textureCube.colorSpace = THREE.SRGBColorSpace   // ✅ 设在纹理上
```

**坑**
- `colorSpace` 是**纹理**的属性，不是材质的属性。`child.material.colorSpace = ...` 这样写不会报错，但**没有任何效果**。
- 环境贴图没有设置 sRGB 时，反射和照明的颜色会偏淡、发灰。

## 6. 物理材质：清漆层 clearcoat

**一句话结论**：`MeshPhysicalMaterial` 可以在材质表面再加一层**透明的光亮涂层**，用来做车漆、亮漆木头、碳纤维这类效果。

### 双层反射

```text
       入射光
         ↓
 ════════════════  ← 清漆层：一部分光在这里直接反射（光滑、清晰）
 ░░░░░░░░░░░░░░░░  ← 基础层：其余的光穿过清漆，按 color / metalness / roughness 反射
```

两层反射叠加，所以车漆既有底漆的金属颗粒感，又有表面的镜面高光。

```js
const mesh = gltf.scene.getObjectByName('外壳01')

mesh.material = new THREE.MeshPhysicalMaterial({
  color: mesh.material.color,  // 沿用模型原来的颜色
  metalness: 1,                // 基础层：金属车漆
  roughness: 0.5,              // 基础层：有金属颗粒的哑光
  clearcoat: 1,                // 清漆层强度
  clearcoatRoughness: 0.01,    // 清漆层粗糙度：接近镜面
  envMap: textureCube,
  envMapIntensity: 2.5,
})
```

| 参数 | 0 | 1 |
|---|---|---|
| `clearcoat` 清漆强度 | 没有清漆，效果和标准材质几乎一样 | 最强的清漆层 |
| `clearcoatRoughness` 清漆粗糙度 | 清漆像镜子，反射清晰锐利 | 清漆像磨砂玻璃，反射模糊 |

**关键**：`clearcoatRoughness` 和基础层的 `roughness` **相互独立**。上面的代码就是"底漆粗糙 0.5 + 清漆光滑 0.01"，这正是车漆的典型组合。

**常见应用**：汽车车漆、抛光木材 / 乐器、碳纤维、潮湿的表面。

## 7. 物理材质：透光 transmission（玻璃）

**一句话结论**：设置 `transmission: 1`，光就能**穿过**材质，再配合 `ior` 折射率，就能做出玻璃。

```js
const glass = gltf.scene.getObjectByName('玻璃01')

glass.material = new THREE.MeshPhysicalMaterial({
  metalness: 0,        // 玻璃不是金属
  roughness: 0,        // 光滑透明；调大就成了磨砂玻璃
  transmission: 1,     // 透光度：1 = 完全透光
  ior: 1.5,            // 折射率：玻璃约 1.5
  envMap: textureCube,
  envMapIntensity: 1,
})
```

| 参数 | 作用 |
|---|---|
| `transmission` | 0 不透光，1 完全透光 |
| `ior` | 折射率，光穿过时偏折的程度（空气 1.0、水约 1.33、玻璃约 1.5） |
| `roughness` | 0 清透，越大越像磨砂玻璃 |

**和 `opacity` 的区别**：`transparent + opacity` 只是让物体整体变淡、半透明；`transmission` 模拟光**穿过**物体，有折射，玻璃后面的物体看起来会变形，更真实。

**坑**
- 玻璃要 `metalness: 0`。金属是不透光的，金属度高了玻璃就不透明了。
- `transmission` 需要额外的渲染计算，大量使用会影响性能。

## 8. 用 lil-gui 调试材质

**一句话结论**：PBR 参数很难凭空写对，用 GUI 拖动滑块实时调整，调到满意后再把数值写回代码。

```js
// gui.js：单独创建一个 GUI 实例，其他文件导入使用
import { GUI } from 'three/addons/libs/lil-gui.module.min.js'
const gui = new GUI()
export default gui
```

```js
const folder = gui.addFolder('车外壳材质')   // 分组

folder.addColor(mesh.material, 'color')                       // 颜色选择器
folder.add(mesh.material, 'metalness', 0, 1, 0.01)            // 滑块：最小、最大、步长
folder.add(mesh.material, 'clearcoatRoughness', 0, 1, 0.01)
  .name('清漆粗糙度')                                          // 自定义显示名称
folder.add(mesh.material, 'envMapIntensity', 0, 5, 0.1)

folder.open()    // 默认展开；close() 默认折叠
```

**写法规律**：`add(对象, '属性名', 最小值, 最大值, 步长)`，GUI 会直接修改这个对象的属性。

**坑**
- 只传了最小值、没传最大值（如 `add(light, 'intensity', 0.2)`），不会显示滑块，只会是一个数字输入框。
- 涉及材质的 GUI 代码要写在 `load` 回调里，因为材质在加载完成后才存在（第 6 章：加载是异步的）。

## 9. 一页速记

| 需求 / 现象 | 解法 |
|---|---|
| 要真实质感 | `MeshStandardMaterial`，调 `metalness` / `roughness` |
| 要车漆、玻璃 | `MeshPhysicalMaterial` |
| 金属看起来发黑 | 缺环境贴图，加 `envMap` |
| 加载环境贴图 | `CubeTextureLoader().setPath().load([px,nx,py,ny,pz,nz])` |
| 反射太模糊 / 太清晰 | 调 `roughness` |
| 环境整体太亮 / 太暗 | 调 `envMapIntensity`（是倍数，可以大于 1） |
| 没有灯光模型也可见 | IBL：环境贴图本身就在照明 |
| 环境贴图颜色发灰 | `textureCube.colorSpace = THREE.SRGBColorSpace`（设在纹理上，不是材质上） |
| 车漆的镜面高光层 | `clearcoat` + `clearcoatRoughness` |
| 玻璃 | `transmission: 1` + `ior: 1.5` + `metalness: 0` + `roughness: 0` |
| 参数调不准 | lil-gui 实时调试 |
