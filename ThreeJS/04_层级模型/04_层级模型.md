# 04 层级模型

本章两个主题：

1. **Group**：把多个物体打包成一个整体来控制
2. **局部坐标与世界坐标**：物体的位置到底是相对谁算的，旋转到底绕哪转

---

## 一、Group：把多个物体当成一个整体

### 1. Group 是什么

- `THREE.Group` 是一个**看不见的容器**，本身没有形状，只用来装子对象（Mesh、Light、Camera，甚至别的 Group 都可以）。
- 对 Group 设置 `position` / `scale` / `rotation`，**所有子对象一起跟着变**。

> 前端类比：Group 就像一个 `position: relative` 的父 div。子元素的 `left/top` 都相对父 div 算，父 div 一移动，子元素整体跟着走。

### 2. 示例代码

```js
import * as THREE from 'three'

const geometry = new THREE.BoxGeometry(20, 20, 20)
const material = new THREE.MeshLambertMaterial({ color: 0x00ffff })

// 两个 mesh 共享同一份 geometry 和 material
const mesh1 = new THREE.Mesh(geometry, material)
const mesh2 = new THREE.Mesh(geometry, material)
mesh2.translateX(50) // mesh2 相对父级往 x 正方向挪 50

// 创建组，把两个 mesh 装进去
const group = new THREE.Group()
group.add(mesh1)
group.add(mesh2)

// 对组做变换，两个子对象一起受影响
group.position.set(50, 50, 50)
group.scale.set(2, 2, 2)
group.rotation.set(Math.PI / 4, Math.PI / 4, Math.PI / 4)

console.log('group.children', group.children) // [mesh1, mesh2]

export default group
```

### 3. 子对象最终出现在哪

关键：**子对象的 `position` 是相对 Group 的，不是相对世界的。**

| | 相对 group 的位置 |
|---|---|
| mesh1 | (0, 0, 0)，正好在 group 原点 |
| mesh2 | (50, 0, 0) |

按三步叠加 group 的变换（先不看旋转）：

**① group 平移到 (50, 50, 50)**：子对象整体跟着挪

```
mesh1：(50,50,50) + (0,0,0)  = (50, 50, 50)
mesh2：(50,50,50) + (50,0,0) = (100, 50, 50)
```

**② group 缩放 2 倍**：子对象离 group 原点的距离也翻倍，自身大小也翻倍

```
mesh1：在 group 原点，距离 0 × 2 还是 0 → 位置不变，仍是 (50, 50, 50)
mesh2：距离 50 × 2 = 100 → (50,50,50) + (100,0,0) = (150, 50, 50)
```

**③ group 旋转**：所有子对象**绕 group 原点**转，也就是绕世界坐标 (50, 50, 50) 转

- mesh1 正好在 group 原点 → 原地转
- mesh2 离 group 原点 100 → 绕着原点甩一圈

> 这和第二部分“旋转永远绕原点（图钉）转”是同一个道理，group 的原点就是它的图钉。

### 4. 变换顺序：写代码的先后无所谓

Three.js 内部计算时**固定按“缩放 → 旋转 → 平移”的顺序**，跟你代码里先设置哪个属性无关：

```js
// 写法一
group.position.set(50, 50, 50)
group.scale.set(2, 2, 2)
group.rotation.set(Math.PI / 4, 0, 0)

// 写法二：顺序打乱，结果和写法一完全一样
group.rotation.set(Math.PI / 4, 0, 0)
group.scale.set(2, 2, 2)
group.position.set(50, 50, 50)
```

注意区分：`position.set` / `rotation.set` / `scale.set` 是**直接设置值**，顺序无所谓；而 `translateX()`、`rotateY()` 这类方法是**在当前状态上叠加**，例如物体先 `rotateY` 再 `translateX`，会沿着转过之后的 x 方向移动，这时调用顺序就有影响了。

### 5. 嵌套 Group

Group 也可以装 Group，形成树状结构（场景图）：

```text
RobotGroup              ← 整体移动/旋转机器人
├── BodyMesh
├── ArmGroup_Left       ← 单独旋转左臂，模拟挥手
│     ├── UpperArmMesh
│     ├── ForearmMesh
│     └── HandMesh
└── ArmGroup_Right
      ├── UpperArmMesh
      ├── ForearmMesh
      └── HandMesh
```

- 转 `ArmGroup_Left`：只有左臂动
- 移动 `RobotGroup`：整个机器人（含手臂）一起走

### 6. 常见用途

- **统一控制**：一辆车由车身、车轮、车灯组成，装进一个 Group，移动车就只改 Group。

  ```js
  const carGroup = new THREE.Group()
  carGroup.add(carBody, wheelFL, wheelFR, wheelBL, wheelBR)
  scene.add(carGroup)
  carGroup.position.x += 10 // 整辆车往前开
  ```

- **逻辑分组**：按功能把场景分块，方便批量显示/隐藏、批量操作。

## 二、局部坐标与世界坐标

### 1. 两种坐标

| | 相对谁 | 前端类比 |
|---|---|---|
| **局部坐标** | 相对**父级**（Group 或 scene） | CSS 的 `left/top`，相对定位父元素 |
| **世界坐标** | 相对**整个场景** | `getBoundingClientRect()`，相对整个页面 |

每一层都只描述“我相对上一层在哪”：

```text
geometry 的顶点  →  相对 mesh 原点
mesh.position   →  相对父级 group
group.position  →  相对 scene
```

世界坐标就是从最外层一路累加下来的结果。

### 2. 核心：只有一个原点，它属于 mesh

这是最容易混淆的地方：**不存在“geometry 原点”和“mesh 原点”两个东西。**

- **mesh 原点**：就是旋转中心，它在父级中的位置 = `mesh.position`
- **geometry**：只是一堆顶点坐标，这些数字的含义是“离 mesh 原点多远”

> 比喻：**图钉钉着一张纸片**
>
> - 图钉 = mesh 原点（旋转永远绕图钉转）
> - 纸片 = geometry（立方体的形状）

### 3. BoxGeometry 默认以自身中心为原点

和 CSS 从左上角算起不同，Three.js 自带的几何体基本都**以中心为原点**。

`BoxGeometry(50, 50, 50)` 在 x、y、z 三个轴上的范围都是 **-25 ~ 25**，图钉钉在立方体正中心。

```js
const geometry = new THREE.BoxGeometry(50, 50, 50)
geometry.computeBoundingBox()
console.log(geometry.boundingBox)
// min: (-25, -25, -25)
// max: ( 25,  25,  25)
```

### 4. geometry.translate 和 mesh.position 的区别

两种写法都能让立方体往 x 正方向挪 25：

```js
// 写法 A：图钉不动，纸片挪 25
geometry.translate(25, 0, 0) // 顶点 x：-25~25 → 0~50

// 写法 B：拔起图钉，连纸一起挪 25
mesh.position.x = 25         // 顶点不变，仍是 -25~25
```

**不旋转时，两者看起来完全一样**，立方体都占据世界 x 的 0 ~ 50：

```text
世界 x：  0          25         50
写法 A：  ●[■■■■■■■■■■■■■■■■■■■■]      图钉在 x=0，即立方体左侧面中心
写法 B：   [■■■■■■■■■■●■■■■■■■■■]     图钉在 x=25，即立方体中心
```

（● = 图钉 = mesh 原点）

**一旋转，区别就出来了**，因为旋转永远绕图钉：

| | 图钉在哪 | `mesh.rotateY()` 的效果 |
|---|---|---|
| 写法 A `geometry.translate` | 立方体左侧面中心 | 绕侧面甩，像门绕门轴转 |
| 写法 B `mesh.position` | 立方体中心 | 原地自转 |

**一句话：`geometry.translate` 决定图钉钉在物体的哪里（旋转中心），`mesh.position` 决定图钉钉在世界的哪里（摆放位置）。**

### 5. 示例代码分析

```js
const geometry = new THREE.BoxGeometry(50, 50, 50)
const material = new THREE.MeshLambertMaterial({ color: 0x00ffff })
const mesh = new THREE.Mesh(geometry, material)

geometry.translate(50 / 2, 0, 0) // 纸片往右挪 25，图钉留在原地 → 图钉落在左侧面中心
mesh.rotateY(Math.PI / 4)        // 绕图钉转 45° → 立方体绕左侧面“甩”过去

export default mesh
```

如果换成 `mesh.position.set(25, 0, 0)`，图钉跟着立方体一起走，仍在中心，旋转就是原地自转。

### 6. 动手验证：两种写法并排对比

`mesh.js`：

```js
import * as THREE from 'three'

const material = new THREE.MeshLambertMaterial({ color: 0x00ffff })

// 写法 A：改 geometry，图钉留在 (0,0,0)，落在立方体左侧面
const geoA = new THREE.BoxGeometry(50, 50, 50)
geoA.translate(25, 0, 0)
const meshA = new THREE.Mesh(geoA, material)
meshA.position.z = -60 // 只是前后错开，方便对比

// 写法 B：改 position，图钉跟着立方体，仍在中心
const geoB = new THREE.BoxGeometry(50, 50, 50) // 必须单独 new，不能共用 geoA
const meshB = new THREE.Mesh(geoB, material)
meshB.position.set(25, 0, 60)

const group = new THREE.Group()
group.add(meshA, meshB)

export { meshA, meshB }
export default group
```

`main.js` 渲染循环里分别旋转两个 mesh（不要转整个 group，否则是绕世界原点转，看不出区别）：

```js
import group, { meshA, meshB } from './mesh.js'

function render() {
  meshA.rotateY(0.01) // 绕左侧面甩
  meshB.rotateY(0.01) // 原地自转
  renderer.render(scene, camera)
  requestAnimationFrame(render)
}
```

## 三、易错点小结

1. **子对象的 position 是相对父级的**，不是世界坐标。
2. **Group 变换顺序固定为缩放 → 旋转 → 平移**，`set` 的先后无所谓；`translateX` / `rotateY` 这类叠加方法的调用顺序才有影响。
3. **只有一个原点（图钉），属于 mesh**；geometry 的顶点坐标是相对这个原点写的。
4. **`geometry.translate` 改的是顶点数据**：常用来调整旋转中心（门轴、钟摆）；而且所有共用这个 geometry 的 mesh 都会受影响。
5. **只想移动物体，就改 `mesh.position`**。
