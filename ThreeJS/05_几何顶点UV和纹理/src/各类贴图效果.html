🎨 Three.js 贴图类型对比讲解

直观理解不同贴图的作用和视觉效果

🌑AO Map（环境光遮蔽贴图）

作用：模拟光线在缝隙、凹陷处被遮挡的效果

原理：黑色区域 = 光线难到达（变暗），白色区域 = 正常受光

效果：增加深度感和立体感，让物体看起来更真实
aoMap: aoTexture, aoMapIntensity: 1.0 // 0-1，控制暗化程度

👻Alpha Map（透明度贴图）

作用：控制材质各部分的透明度

原理：黑色 = 完全透明，白色 = 完全不透明，灰色 = 半透明

效果：实现镂空、树叶、玻璃裂纹等效果
alphaMap: alphaTexture, transparent: true // 必须开启透明

✨Specular Map（高光贴图）

作用：控制表面哪些区域更亮、更有光泽

原理：白色 = 高反射（亮），黑色 = 低反射（暗）

效果：模拟金属光泽、湿润表面、抛光区域
specularMap: specularTexture, shininess: 30 // 配合使用，控制光泽度

💡Light Map（光照贴图）

作用：预先烘焙的光照效果，提升性能

原理：保存了场景光照的计算结果，直接贴到物体上

效果：静态光照、阴影、间接光照（类似烘焙光照）
lightMap: lightTexture, lightMapIntensity: 1.0 // 光照强度
贴图类型 颜色含义 主要用途 材质支持 性能影响
AO Map 黑=暗，白=亮 增加凹陷处阴影 StandardPBR 低
Alpha Map 黑=透明，白=不透明 镂空、树叶、玻璃 BasicStandardPBR 中
Specular Map 白=高光，黑=哑光 控制反光强度 Standard 低
Light Map RGB颜色=光照颜色 烘焙静态光照 BasicStandardPBR 低（提升性能）

🔑 关键要点总结

  • AO Map：让缝隙变暗，增强深度感。不需要强度属性也能用，但 aoMapIntensity 可以控制效果强弱
  • Alpha Map：控制透明度，必须配合 transparent: true 使用。黑色部分会完全消失
  • Specular Map：控制反光强度，只在 MeshPhongMaterial/MeshStandardMaterial 中生效。白色区域更亮
  • Light Map：预计算的光照，可以大幅提升性能。适合静态场景，需要第二套 UV（uv2）
  • 复合使用：这些贴图可以同时使用，它们的效果会叠加（相乘混合）
  • 性能优化：使用 Light Map 代替实时光照可以显著提升帧率
