# 09 管道漫游

> 效果：相机钻进一根弯弯曲曲的砖墙管道里，沿着管道一路往前飞，到终点后回到起点重新开始。
>
> 文件：`mesh.js`（路径、管道、贴图、路径上的点）、`index.js`（相机沿着点移动）、`diffuse.jpg`（砖墙贴图）

> 📷 待补截图：相机在管道内部前进的画面

**整体思路只有三步**：

1. 画一条弯曲的路线（曲线）
2. 沿着这条路线造一根管子，贴上砖墙
3. 在路线上取一串间距相等的点，相机每一帧跳到下一个点，并看向再下一个点

---

## 1. 定义路线：CatmullRomCurve3

**一句话结论**：给几个点，`CatmullRomCurve3` 会生成一条**穿过所有点**的平滑曲线。

**代入数字**：本章给了 6 个点，生成的曲线总长约 **371.6**。

```js
const path = new THREE.CatmullRomCurve3([
  new THREE.Vector3(-50, 20, 90), // 起点
  new THREE.Vector3(-10, 40, 40),
  new THREE.Vector3(0, 0, 0),
  new THREE.Vector3(60, -60, 0),
  new THREE.Vector3(90, -40, 60),
  new THREE.Vector3(120, 30, 30), // 终点
]);
console.log(path.getLength()); // 371.6
```

**坑**

- 曲线是**不闭合**的，终点 (120,30,30) 和起点 (-50,20,90) 不相连。所以漫游到终点后，相机会瞬间跳回起点（见第 5 节）。

---

## 2. 沿路线造管道：TubeGeometry

**一句话结论**：`TubeGeometry` 让一个圆沿着曲线"扫"一遍，生成一根管子。

```js
const geometry = new THREE.TubeGeometry(path, 200, 5, 30);
//                                       │     │   │   └ 圆周分成 30 段：越多越圆
//                                       │     │   └ 管道半径 5
//                                       │     └ 沿路线分成 200 段：越多弯道越平滑
//                                       └ 沿哪条曲线
```

**代入数字**：半径 5，管子一圈的周长 = 2 × π × 5 ≈ **31.4**。

```js
const material = new THREE.MeshLambertMaterial({
  map: texture,
  side: THREE.DoubleSide, // 关键：相机在管子里面
});
```

**坑**

- **必须 `DoubleSide`。** 管道的面默认朝外，只有从外面才看得见。相机钻进管子里，看到的是面的背面，不设双面的话，管子内部是透明的，什么都看不到。

---

## 3. 给管道贴砖墙：贴图重复

**一句话结论**：贴图默认只铺一次，会被拉得很长；设置重复后，砖块才是正常比例。

**贴图在管道上是怎么铺的**：贴图的**横向**沿着管道的**长度**方向铺，**纵向**绕着管道的**一圈**铺。

**代入数字**

- 不重复：一张砖墙图被拉长到 371.6 长、绕一圈 31.4，横向被拉长了约 12 倍，砖块会变成细长条。
- `repeat.x = 10`：横向重复 10 次，每张图铺 371.6 ÷ 10 ≈ **37.2** 长，绕一圈 **31.4**，接近正方形，砖块比例正常 ✅

```js
const texLoader = new THREE.TextureLoader();
const texture = texLoader.load("./diffuse.jpg");
texture.colorSpace = THREE.SRGBColorSpace; // 颜色贴图要标记为 sRGB，颜色才不会发白

texture.wrapS = THREE.RepeatWrapping; // 允许横向重复
texture.repeat.x = 10;                // 横向（沿管道长度）重复 10 次
```

**坑**

- **只设 `repeat` 不设 `wrapS = RepeatWrapping` 不会重复**，超出的部分只会把图片边缘的像素拉长。
- **原代码的颜色设置在当前版本里已经失效。** 原代码写的是 `texture.encoding = THREE.sRGBEncoding` 和 `renderer.outputEncoding = THREE.sRGBEncoding`，这是旧版 three.js 的写法。本项目用的 0.174 版本里，`THREE.sRGBEncoding` 已经被删掉了，值是 `undefined`，这两行不会报错，但什么都没做，砖墙颜色会偏白、发灰。新版写法：
  - 贴图：`texture.colorSpace = THREE.SRGBColorSpace`
  - 渲染器：不用写，新版默认就是 sRGB 输出，删掉 `outputEncoding` 那行即可

## 4. 在路线上取等距的点：getSpacedPoints

**一句话结论**：`getSpacedPoints(500)` 把曲线切成 500 段**一样长**的小段，返回 501 个点。相机按顺序一个点一个点地走，速度就是均匀的。

**为什么是 501 个**：一根绳子分成 500 段，需要 501 个点来标记（每段的起点，再加上最后的终点），所以是 500 + 1 = **501**。

**代入数字**：曲线总长 371.6，分成 500 段，每段约 **0.74**。实测对比两个方法：

| 方法 | 点数 | 相邻两点的距离 | 漫游效果 |
|---|---|---|---|
| `getSpacedPoints(500)` | 501 | 0.733 ~ 0.753，几乎一样 | 匀速 ✅ |
| `getPoints(500)` | 501 | 0.502 ~ 1.013，相差一倍 | 忽快忽慢 ❌ |

```js
const pointsArr = path.getSpacedPoints(500); // 501 个间距相等的点
export { group, pointsArr };
```

**坑**

- `getPoints` 是按"曲线参数"平均取点，不是按长度平均取点，弯道和直道上的点疏密不一样。漫游一定要用 `getSpacedPoints`。

## 5. 相机沿着点漫游

**一句话结论**：每一帧，相机**站到**第 i 个点，**看向**第 i+1 个点，然后 i 加 1。

**代入数字**

- 第 0 帧：站在 pointsArr[0]，看向 pointsArr[1]
- 第 1 帧：站在 pointsArr[1]，看向 pointsArr[2]
- ……
- 第 499 帧：站在 pointsArr[499]，看向 pointsArr[500]（终点）
- 第 500 帧：i = 500，进入 else，i 归零，下一帧回到起点
- 走完一圈 500 帧，60Hz 屏幕上约 **8.3 秒**，相机每秒前进约 0.74 × 60 ≈ **44.6**

```js
import { group, pointsArr } from "./mesh.js";

const camera = new THREE.PerspectiveCamera(90, width / height, 1, 3000);
// fov = 90，视野比较宽，在管道里更有"钻进去"的感觉

let i = 0;
function render() {
  if (i < pointsArr.length - 1) {
    camera.position.copy(pointsArr[i]); // 站到当前点
    camera.lookAt(pointsArr[i + 1]);    // 看向下一个点 = 看向前进方向
    i += 1;
  } else {
    i = 0; // 走到终点，回到起点
  }
  renderer.render(scene, camera);
  requestAnimationFrame(render);
}
render();
```

**为什么看向下一个点就是"看向前方"**：两个相邻点只隔 0.74，非常近，从当前点指向下一个点的方向，就是曲线在这里的前进方向。

**坑**

- **每帧都要重新 `lookAt`**：和第 04 章圆周运动一样，挪了 position，朝向不会自动跟着变。
- **和 OrbitControls 冲突**：渲染循环每帧都会覆盖相机的位置和朝向，鼠标操作无效。原代码已经把控制器注释掉了，这是对的。
- **终点会瞬间跳回起点**：曲线不闭合，回到起点是一次"瞬移"。
- **转速和屏幕刷新率有关**：120Hz 屏幕走完一圈只要约 4.2 秒。
- **路线不要竖直上下**：相机的 up 默认是 y 轴，如果某一段路线正好竖直朝上或朝下，视线就和 up 平行，画面朝向会乱（见第 05 章）。本章路线最陡的地方和 y 轴的夹角约 28°，不会碰到这个问题。

## 6. 本章完整代码（已修正）

**mesh.js**

```js
import * as THREE from "three";

const group = new THREE.Group();

// 1. 路线：穿过 6 个点的平滑曲线
const path = new THREE.CatmullRomCurve3([
  new THREE.Vector3(-50, 20, 90),
  new THREE.Vector3(-10, 40, 40),
  new THREE.Vector3(0, 0, 0),
  new THREE.Vector3(60, -60, 0),
  new THREE.Vector3(90, -40, 60),
  new THREE.Vector3(120, 30, 30),
]);

// 2. 管道：沿路线分 200 段，半径 5，圆周 30 段
const geometry = new THREE.TubeGeometry(path, 200, 5, 30);

// 3. 砖墙贴图：沿管道长度重复 10 次
const texLoader = new THREE.TextureLoader();
const texture = texLoader.load("./diffuse.jpg");
texture.colorSpace = THREE.SRGBColorSpace;
texture.wrapS = THREE.RepeatWrapping;
texture.repeat.x = 10;

const material = new THREE.MeshLambertMaterial({
  map: texture,
  side: THREE.DoubleSide, // 相机在管道内部，必须双面
});
const mesh = new THREE.Mesh(geometry, material);
group.add(mesh);

// 4. 路线上 501 个等距点，供相机漫游
const pointsArr = path.getSpacedPoints(500);

export { group, pointsArr };
```

**index.js**

```js
import * as THREE from "three";
import { group, pointsArr } from "./mesh.js";

// 场景
const scene = new THREE.Scene();
scene.add(group);

// 光源
const directionalLight = new THREE.DirectionalLight(0xffffff, 3);
directionalLight.position.set(100, 60, 50);
scene.add(directionalLight);
const ambient = new THREE.AmbientLight(0xffffff, 0.4);
scene.add(ambient);

// 相机
const width = window.innerWidth;   // canvas 画布宽度
const height = window.innerHeight; // canvas 画布高度
const camera = new THREE.PerspectiveCamera(90, width / height, 1, 3000);

// 渲染器（新版默认 sRGB 输出，不需要再设置 outputEncoding）
const renderer = new THREE.WebGLRenderer({
  antialias: true,
  preserveDrawingBuffer: true, // 需要把画布内容下载成图片时才要开，本章用不到
});
renderer.setPixelRatio(window.devicePixelRatio);
renderer.setSize(width, height);
document.body.appendChild(renderer.domElement);

// 漫游：每帧站到第 i 个点，看向第 i+1 个点
let i = 0;
function render() {
  if (i < pointsArr.length - 1) {
    camera.position.copy(pointsArr[i]);
    camera.lookAt(pointsArr[i + 1]);
    i += 1;
  } else {
    i = 0;
  }
  renderer.render(scene, camera);
  requestAnimationFrame(render);
}
render();

// 画布跟随窗口变化
window.onresize = function () {
  const width = window.innerWidth;
  const height = window.innerHeight;
  renderer.setSize(width, height);
  camera.aspect = width / height;
  camera.updateProjectionMatrix();
};
```
