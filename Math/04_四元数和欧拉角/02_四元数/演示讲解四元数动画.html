🎯 四元数朝向中心点的数学原理

步骤 1: 计算方向向量

// 从当前位置指向目标的向量 const directionVector = target.clone().sub(currentPosition); // 标准化为单位向量 const b = directionVector.normalize();
b⃗ = (target - position) / |target - position|

这个向量 b⃗ 就是我们希望物体朝向的方向。

步骤 2: 定义初始朝向

// 物体的初始朝向（比如向右） const a = new THREE.Vector3(1, 0, 0);

向量 a⃗ 代表物体在初始状态下的朝向方向。

步骤 3: 计算旋转四元数

// 创建四元数，将a旋转到b const quaternion = new THREE.Quaternion(); quaternion.setFromUnitVectors(a, b);
q = 旋转四元数，使得 a⃗ → b⃗

🔬 四元数的数学推导

setFromUnitVectors(a, b) 方法的内部原理：

1. 计算点积：dot = a⃗ · b⃗ = |a⃗||b⃗|cos(θ)
2. 计算叉积：cross = a⃗ × b⃗
3. 四元数：q = (w, x, y, z)
其中：w = √((|a⃗||b⃗|)² + a⃗·b⃗) / √2
(x,y,z) = cross / √2

步骤 4: 应用旋转

// 将四元数应用到物体上 object.quaternion.copy(quaternion); // 或者与现有旋转结合 object.quaternion.multiply(quaternion);

💡 关键优势

  • 万向锁免疫：四元数不会出现万向锁问题
  • 平滑插值：可以实现平滑的SLERP插值
  • 计算高效：比矩阵运算更高效
  • 组合简单：通过乘法easily组合多个旋转
