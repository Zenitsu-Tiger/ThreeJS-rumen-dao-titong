# 🎨 Three.js =>从入门到提桶=> 系统学习笔记

> 一个由笔者独立整理和编撰的 Three.js 完整学习路径，从数学基础到实战应用的系统化学习资源。

## 📖 项目简介

这是一个基于官方文档、技术博客和视频教程深度学习后，独立整理编撰的 Three.js 学习笔记。项目涵盖了从底层数学原理到 Three.js 各个核心模块的完整知识体系，每个章节都包含作者精心总结的学习要点和代码示例。
**请着重阅读每章的README.md理解知识点，这是笔者的讲解笔记内容。**

**适合人群：**
- Three.js 初学者，希望系统学习 3D 图形编程
- 前端开发者，想要掌握 WebGL 和 3D 可视化技术
- 有一定 JavaScript 基础，希望深入理解 Three.js 底层原理的开发者

## ✨ 项目特色

- 📚 **系统完整**：从数学基础到高级应用，覆盖 Three.js 核心知识点
- 🔍 **深入浅出**：每个章节包含详细的原理讲解和实用示例
- 📝 **独立编撰**：基于多方资源整合，融入作者实践经验
- 🎯 **循序渐进**：科学的学习路径，适合逐步深入学习
- 💡 **实战导向**：理论与实践结合，包含真实项目案例

## 📂 目录结构

### 📐 Math 模块（数学基础）

数学是 3D 图形编程的基石，本模块涵盖 Three.js 开发所需的核心数学知识：

```
Math/
├── 01_坐标系与三角函数/     # 3D 空间坐标系统、三角函数应用
├── 02_位移和加速度/         # 向量运动、速度与加速度计算
├── 03_向量点乘、叉乘/       # 向量运算及其在 3D 中的应用
├── 04_四元数和欧拉角/       # 旋转表示方法、万向节死锁问题
└── 05_矩阵/                 # 变换矩阵、模型视图投影矩阵
```

### 🎮 Three.js 模块（核心技术）

系统学习 Three.js 从入门到进阶的完整知识体系：

```
ThreeJS/
├── 01_快速入门/                  # 场景、相机、渲染器基础
├── 02_几何体的顶点模型/          # BufferGeometry、顶点数据结构
├── 03_模型对象和材质/            # Mesh、Material 核心概念
├── 04_层级模型/                  # Group、Object3D 层级关系
├── 05_几何顶点UV和纹理/          # UV 映射、纹理贴图技术
├── 06_gltf/                      # glTF 模型加载与处理
├── 07_PBR材质/                   # 物理渲染材质原理与应用
├── 08_渲染器和前端UI页面/        # WebGLRenderer、界面集成
├── 09_生成曲线和几何体/          # 程序化生成、曲线建模
├── 10_相机和投影/                # 透视/正交相机、视锥体
├── 11_光源与阴影/                # 光照系统、阴影贴图
├── 12_精灵模型/                  # Sprite、始终面向相机的对象
├── 13_后期处理/                  # EffectComposer、后期特效
├── 14_射线拾取模型/              # Raycaster、交互拾取
├── 15_场景标注标签信息/          # HTML 标签与 3D 场景结合
├── 16_关键帧动画/                # AnimationClip、动画系统
├── 17_cannon-es/                 # 物理引擎集成与应用
└── 18_粮仓基地/                  # 综合实战项目案例
```

## 🗺️ 学习路线建议



### 阶段一：Three.js 入门（2-3 周）
1. `01_快速入门` - 搭建第一个 Three.js 场景
2. `02_几何体` → `03_材质` → `04_层级模型` - 掌握基本对象
3. `05_纹理` - 让模型更真实
4. `10_相机` 和 `11_光源` - 控制视角和光影

### 阶段二：进阶应用（1-2 周）
1. `06_gltf` 和 `07_PBR材质` - 加载和渲染真实模型
2. `09_曲线生成` - 程序化建模
3. `14_射线拾取` 和 `15_标注` - 增加交互功能
4. `16_动画` - 让场景动起来

### 阶段三：高级特性（1-2 周）
1. `13_后期处理` - 提升视觉效果
2. `17_cannon-es` - 物理引擎
3. `18_粮仓基地` - 综合实战项目

### 阶段五：数学基础（1-2 周）
1. 从 `Math/01_坐标系与三角函数` 开始，理解 3D 空间的基本概念
2. 学习向量运算，为后续物体变换打基础
3. 掌握四元数和矩阵，理解 Three.js 内部的数学运算
