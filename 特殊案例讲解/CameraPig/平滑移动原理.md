## 🎯 核心概念：这不是模型，是相机控制器！

**CameraRig** = Camera（相机） + Rig（装备/支架）

它的作用：**让相机跟随鼠标移动**！

------

## 📊 先看效果

想象你在看一个3D场景：

```
鼠标在左边 → 相机向左移 → 你看到场景的右侧
鼠标在右边 → 相机向右移 → 你看到场景的左侧
鼠标在上面 → 相机向上移 → 你看到场景的下方
鼠标在下面 → 相机向下移 → 你看到场景的上方
```

**就像你拿着手机拍照，手机左右移动，画面就会变化！**

## 🔍 state 对象详解

`useFrame((state, delta) => {...})` 中的 **state** 包含：

```javascript
state = {
  camera: THREE.Camera,              // 相机对象
  scene: THREE.Scene,                // 场景对象
  gl: THREE.WebGLRenderer,           // 渲染器
  clock: THREE.Clock,                // 时钟
  
  // 🎯 关键！鼠标位置（归一化坐标）
  pointer: {
    x: -0.5,  // 范围：-1（最左）到 1（最右）
    y: 0.3    // 范围：-1（最下）到 1（最上）
  },
  
  // 🎯 关键！视口信息
  viewport: {
    width: 10,    // 3D世界中的宽度
    height: 7.5,  // 3D世界中的高度
    aspect: 1.33  // 宽高比
  }
}
```

```javascript
const targetPosition = [
```

```javascript
// X轴计算：
-1 + (0 × 10) / 3 = -1 + 0 = -1

// Y轴计算：
(1 + 0) / 2 = 0.5

// 结果：相机位置 = [-1, 0.5, 5.5]
```

### 🖱️ 情况2：鼠标在右上角

```javascript
pointer.x = 1     // 鼠标最右边
pointer.y = 1     // 鼠标最上面
viewport.width = 10

// X轴计算：
-1 + (1 × 10) / 3 = -1 + 3.33 = 2.33

// Y轴计算：
(1 + 1) / 2 = 1

// 结果：相机位置 = [2.33, 1, 5.5]
```

### 🖱️ 情况3：鼠标在左下角

```javascript
pointer.x = -1    // 鼠标最左边
pointer.y = -1    // 鼠标最下面
viewport.width = 10

// X轴计算：
-1 + (-1 × 10) / 3 = -1 - 3.33 = -4.33

// Y轴计算：
(1 + (-1)) / 2 = 0

// 结果：相机位置 = [-4.33, 0, 5.5]

```

## 🌟 easing.damp3 详解

这是 **maath** 库提供的平滑插值函数。

### 语法：

```javascript
easing.damp3(
  current,   // 当前值（会被修改）
  target,    // 目标值
  smoothing, // 平滑度（0-1，越大越慢）
  delta      // 时间增量
)
```

### 作用：

让相机**平滑**地移动到目标位置，而不是瞬间跳过去。

**类比：**

- ❌ 没有平滑：相机瞬移（像瞬间移动）
- ✅ 有平滑：相机滑动（像坐滑梯）

## 🔄 React Three Fiber vs 原生 Three.js 对照表

### **React Three Fiber 版本：**

```jsx
function CameraRig() {
  useFrame((state, delta) => {
    easing.damp3(
      state.camera.position,
      [-1 + (state.pointer.x * state.viewport.width) / 3, 
       (1 + state.pointer.y) / 2, 
       5.5],
      0.5,
      delta
    )
    state.camera.lookAt(0, 0, 0)
  })
  return null
}
```

### **原生 Three.js 版本：**

#### 1️⃣ **state.pointer（鼠标位置）**

```javascript
// React Three Fiber 自动提供
state.pointer.x  // -1 到 1
state.pointer.y  // -1 到 1

// 原生 Three.js 需要自己计算
const pointer = { x: 0, y: 0 };

window.addEventListener('mousemove', (event) => {
  pointer.x = (event.clientX / window.innerWidth) * 2 - 1;
  pointer.y = -(event.clientY / window.innerHeight) * 2 + 1;
});
```

**转换公式解释：**

```javascript
// 屏幕坐标 → 归一化坐标
clientX: 0 → 800 → 1600     转换为    -1 → 0 → 1
clientY: 0 → 600 → 1200     转换为     1 → 0 → -1（注意Y轴反转）

公式：
x = (clientX / width) * 2 - 1
    ↓
    0/1600 * 2 - 1 = -1    (最左边)
    800/1600 * 2 - 1 = 0   (中间)
    1600/1600 * 2 - 1 = 1  (最右边)
```

------

#### 2️⃣ **state.viewport（视口尺寸）**

```javascript
// React Three Fiber 自动提供
state.viewport.width   // 例如：10
state.viewport.height  // 例如：7.5

// 原生 Three.js 需要自己计算
function calculateViewport() {
  const distance = camera.position.z;  // 相机距离
  const vFov = camera.fov * Math.PI / 180;  // 视野角度（弧度）
  
  // 🎯 关键公式！
  viewportHeight = 2 * Math.tan(vFov / 2) * distance;
  viewportWidth = viewportHeight * camera.aspect;
}
```

**为什么要算这个？**

```
               /|
              / |
   相机 👁   /  | viewportHeight
            /   |
           /θ/2 |
          /_____|
          distance

tan(θ/2) = (viewportHeight/2) / distance
所以: viewportHeight = 2 × tan(θ/2) × distance
```

------

#### 3️⃣ **easing.damp3（平滑插值）**

```javascript
// React Three Fiber 使用 maath 库
easing.damp3(current, target, smoothing, delta)

// 原生 Three.js 手写实现
function damp3(current, target, smoothing, delta) {
  // 计算插值因子
  const t = 1 - Math.pow(1 - smoothing, delta * 60);
  
  // 对XYZ三个轴分别插值
current.x = camera.position.x  // 相机当前X坐标
current.y = camera.position.y  // 相机当前Y坐标
current.z = camera.position.z  // 相机当前Z坐标
}
```

**插值因子 t 的计算原理：**

```javascript
smoothing = 0.5
delta = 0.016 (60fps 时约为 1/60 秒)

t = 1 - Math.pow(1 - 0.5, 0.016 * 60)
  = 1 - Math.pow(0.5, 0.96)
  = 1 - 0.5137
  = 0.4863

// 意思是：每帧向目标移动约48.63%的距离
```

### 1️⃣ 什么是插值因子 t？

#### 🎯 一句话解释：

> **t 是"每帧移动多少比例"的控制器**

#### 📊 直观理解：

```
从 A 点移动到 B 点：

A ━━━━━━━━━━━━━━ B
0%              100%

t = 0.1  → 每次移动剩余距离的 10%
t = 0.5  → 每次移动剩余距离的 50%
t = 1.0  → 一次性直接到达（瞬移）
```

**举例说明平滑插值：**

```javascript
假设：
当前位置 = 0
目标位置 = 10
smoothing = 0.5

第1帧: 0 + (10 - 0) * 0.486 = 4.86
第2帧: 4.86 + (10 - 4.86) * 0.486 = 7.36
第3帧: 7.36 + (10 - 7.36) * 0.486 = 8.64
第4帧: 8.64 + (10 - 8.64) * 0.486 = 9.30
第5帧: 9.30 + (10 - 9.30) * 0.486 = 9.64
...
无限接近10，但永远不会瞬间到达
```

## 💡 关键概念总结

### **1. 为什么 return null？**

```jsx
function CameraRig() {
  useFrame(...)
  return null  // ← 不渲染任何3D对象，只是控制器
}
```

**CameraRig 不是模型**，它只是一个**逻辑组件**，专门负责控制相机！

### **2. state 是什么？**

```javascript
state = {
  camera: 相机对象,
  scene: 场景对象,
  gl: 渲染器,
  clock: 时钟,
  pointer: 鼠标位置,
  viewport: 视口尺寸,
  ...
}
```

React Three Fiber 把 Three.js 的各种对象打包成一个 `state`，方便你使用。

### **3. 为什么要平滑插值？**

**❌ 没有平滑：**
```
鼠标移动 → 相机瞬移 → 画面跳跃（不舒服）
```

**✅ 有平滑：**
```
鼠标移动 → 相机滑动 → 画面流畅（舒服）
```

### **4. delta 的作用？**

保证动画**帧率独立**：

- 60fps 时：delta ≈ 0.016 秒
- 30fps 时：delta ≈ 0.033 秒

使用 delta 后，无论帧率多少，动画速度都一致！
