🔆 LED 正弦波动画原理演示

交互式可视化教程 - 理解你代码中的 LED 闪烁算法

⚙️ 参数控制

频率: 15900 Hz
核心算法：
const
rand = 1.59
const
t = Math.round(
  (1 + Math.sin(
    rand × 10000 +
    time × rand
  )) / 2
)
color.setRGB
(0, t×1.1, t)

① 正弦波原始值

0.0000
范围: -1 到 1

② 归一化值

0.5000
范围: 0 到 1

③ 二值化结果

0
结果: 0 (OFF) 或 1 (ON)

🎯 步骤 ① 随机偏移

rand = Math.abs(2 + position.x)
每个LED根据位置获得不同的rand值，使它们有不同的闪烁节奏，避免同步闪烁。

🌊 步骤 ② 正弦振荡

Math.sin(rand × 10000 + time × rand)
乘以10000产生高频振荡，让LED快速闪烁。time × rand 提供时间相关的相位变化。

📊 步骤 ③ 归一化

(1 + sinValue) / 2
将正弦波从 [-1, 1] 转换为 [0, 1]，为下一步二值化做准备。

⚡ 步骤 ④ 二值化

Math.round(normalized)
四舍五入得到 0 或 1，形成清晰的开/关效果。0=灯灭(黑)，1=灯亮(青绿)。
